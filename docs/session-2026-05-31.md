### 3. Change Order Parser Built

Automated pipeline: file dropped in Google Drive → Gemini parses → draft project in Supabase.

**Files created** (all in `scripts/change-order-parser/`):
- `AppsScript.js` — Complete Google Apps Script pipeline
- `schema.json` — JSON schema for parser output
- `SETUP.md` — Step-by-step setup guide

**Architecture:**
- Google Apps Script polls "HC Finishing Uploads" Drive folder every 5 minutes
- New files (PDF, DOCX, XLSX, images) are converted to text via Drive OCR
- Text sent to Gemini 2.0 Flash with a universal extraction prompt
- Gemini returns structured JSON (project info, rooms with all material categories, change order line items, flags for ambiguous data)
- JSON transformed to match the presentation engine's `selections_json` format
- Inserted as a draft project in Supabase `projects` table
- File moved to "Processed" subfolder

**STATUS: Code complete. Apps Script NOT YET deployed to script.google.com.**
